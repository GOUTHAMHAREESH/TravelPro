# Travel Plus

An academic React project for a comprehensive travel platform.

## Features

- **Home Page**: Banner, About Us, Latest Travels, Top Destinations, and Quick Options
- **Travels Page**: Display of travel stories documented from start to finish
- **Destinations Page**: Explore popular travel destinations with details
- **Hotels Page**: Browse and book hotels with booking functionality
- **Cabs Page**: Book cab services with different vehicle options
- **About Page**: Information about Travel Plus
- **Contact Page**: Contact form and company information

## Tech Stack

- React 18.2.0
- React Router DOM 6.20.0
- Vite 5.0.8
- JavaScript (No TypeScript)

## Installation

1. Install dependencies:
```bash
npm install
```

2. Start development server:
```bash
npm run dev
```

3. Build for production:
```bash
npm run build
```
